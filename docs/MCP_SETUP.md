# Connect CockroachDB Cloud MCP

Northstar uses the CockroachDB Cloud MCP server as its second required CockroachDB tool. The MCP client is separate from the running Northstar application; use read-only inspection prompts for the demo so it does not change user data.

## 1. Get the cluster ID

Open the CockroachDB Cloud cluster. Copy the ID from the URL:

```text
https://cockroachlabs.cloud/cluster/CLUSTER_ID/overview
```

## 2. Configure authentication

OAuth is preferred because its tokens are short-lived:

Add the MCP configuration snippet generated by the CockroachDB Cloud Console to your local `.codex/config.toml`, then authenticate:

```bash
codex mcp login cockroachdb-cloud
```

Never commit `.codex/config.toml`; this repository ignores it because it identifies your cluster.

## 3. Restart and verify Codex

Restart the Codex app or IDE extension from an environment containing those variables. Then check:

```bash
codex mcp list
```

In an interactive Codex session, enter `/mcp`. `cockroachdb-cloud` should be connected.

Useful demo prompts:

```text
List the tables that store Northstar candidate memory.
Show the schema of candidate_memories.
Count memories by category for demo-user.
Explain the vector search query used to retrieve memories for a job match.
```

## Configuration

The active local configuration is `.codex/config.toml`. Generate it from the CockroachDB Cloud Console so the endpoint and cluster header match the cluster used by `DATABASE_URL`.
